# HARD BOUNDARIES — NEVER without Yu

These are absolute rails for the KIMOTO STUDIO Sales Plugin. None of the items below may
happen automatically or on a casual message. They require Yu's explicit, in-context approval.

## NEVER without Yu (checklist)

- [ ] **No auto-send.** The system never sends outreach on its own.
- [ ] **No form submit.** Never click/submit a contact form, ever, in current scope.
- [ ] **No DM.** Never send a direct message on any platform.
- [ ] **No phone.** Never place a call or trigger any phone contact.
- [ ] **No marking `sent=1` before Yu explicitly confirms** the send happened.
- [ ] **No fabricated URLs.** Only reference real, deployed, verified URLs.
- [ ] **No fake testimonials.** Never invent reviews, quotes, or customer voices.
- [ ] **No before/after.** No before/after imagery, copy, or implied transformation.
- [ ] **No medical/beauty efficacy claims.** See `FORBIDDEN_CLAIMS.md`.
- [ ] **No git push unless Yu approves.** Local commits/pushes wait for Yu's word.

## Deploy is the one exception

Deploy (preview AND public production) **IS allowed/AUTO**. Deploying a demo — even publicly —
does NOT contact anyone. **Deploy ≠ send.** Sending/emailing/forming the URL stays Yu-manual.

Deployed content must still be honest, claim-safe (see `FORBIDDEN_CLAIMS.md`), and secret-free
(no .env / tokens / webhooks in any deployed file). A claim or secret leak in a deploy =
STOP + WARNING + take the page down.
